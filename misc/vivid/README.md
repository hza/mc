# vivid files

`filetypes.yml` and `themes/*.yml` are copied unchanged from
[vivid](https://github.com/sharkdp/vivid) at commit `efc43e8`. vivid is
dual-licensed under MIT or Apache-2.0; both license texts are included here.

Midnight Commander reads them to color file names. See the "Vivid color themes"
section of `.github/README.md`.
